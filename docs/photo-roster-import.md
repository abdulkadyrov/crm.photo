# Добавление списка класса по фотографиям

Откройте класс → «Список детей» (для пустого класса — «Добавить полный класс детей») → «Добавить по фотографиям».

1. Выберите до 10 JPG/PNG/WebP одного класса, до 20 МБ каждый.
2. На каждой фотографии выделите область со списком, включая номера строк. Рамку можно нарисовать пальцем/мышью или задать границы в процентах. Исключите рамку монитора, оценки и соседние столбцы.
3. Нажмите «Распознать фото». Можно отменить обработку или закрыть диалог.
4. Сверьте черновик с фотографиями. Оставьте фамилию и имя, по одному ребёнку в строке. Составные имена сохраняйте через дефис. Исходный распознанный текст доступен под каждой фотографией.
5. Отметьте сверку, перенесите результат в общий список, нажмите «Проверить изменения», затем подтвердите сохранение.

Импорт дополняет текущий список, сохраняя существующие карточки. Автоматически объединяются только одинаковые имена с одинаковым номером строки на разных фото. Без номера повтор остаётся для ручной проверки. Тёзки с разными номерами остаются отдельными строками. Конфликтующие и пропущенные номера отмечаются. Без номера невозможно надёжно определить полноту класса.

Распознавание локальное: фото не отправляются во внешний сервис и не сохраняются в базе. Для первой загрузки движка нужен интернет; дальнейшая работа офлайн зависит от наличия файлов в кэше браузера. API-ключи не нужны.

## Ограничения и проверка

Это OCR-черновик, а не гарантированно полный список. Муар на фотографиях монитора, наклон, обрезанные строки и редкие имена ухудшают результат. Проверка пользователем обязательна; неподходящие строки могут быть пропущены. Фотографии разных классов нужно загружать отдельно.

Проверено локально на приложенном печатном списке: распознавание после выделения столбца, редактирование, перенос, сохранение и повторное открытие в Chromium, ширины 375 и 1440. Фотографии монитора дали неполные результаты; автоматическое получение всех 20 учеников без исправлений не подтверждено.

Тесты парсера покрывают составные имена, переносы, отчества, пересечения фотографий, конфликт номеров, пропуски, тёзок и повторный импорт. Реальные фотографии и списки не включены в репозиторий.
