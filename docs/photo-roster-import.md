# Добавление списка класса по фотографиям

Откройте класс → «Список детей» (для пустого класса — «Добавить полный класс детей») → «Добавить по фотографиям».

1. Выберите до 10 JPG/PNG/WebP одного класса, до 20 МБ каждый.
2. На каждой фотографии выделите область со списком, включая номера строк. Рамку можно нарисовать пальцем/мышью или задать границы в процентах. Исключите рамку монитора, оценки и соседние столбцы.
3. Для снимков экрана включите «Фото монитора: убрать полосы и выровнять строки». Нажмите «Распознать фото». Можно отменить обработку или закрыть диалог.
4. Сверьте черновик с фотографиями. Оставьте фамилию и имя, по одному ребёнку в строке. Составные имена сохраняйте через дефис. Исходный распознанный текст доступен под каждой фотографией.
5. Отметьте сверку, перенесите результат в общий список, нажмите «Проверить изменения», затем подтвердите сохранение.

Импорт дополняет текущий список, сохраняя существующие карточки. Автоматически объединяются только одинаковые имена с одинаковым номером строки на разных фото. Без номера повтор остаётся для ручной проверки. Тёзки с разными номерами остаются отдельными строками. Конфликтующие и пропущенные номера отмечаются. В режиме монитора повреждённые номера могут восстанавливаться по устойчивой последовательности соседних строк, о чём выводится предупреждение. Имена и отсутствующие ученики не достраиваются. Без номера невозможно надёжно определить полноту класса.

Распознавание локальное: фото не отправляются во внешний сервис и не сохраняются в базе. Для первой загрузки движка нужен интернет; дальнейшая работа офлайн зависит от наличия файлов в кэше браузера. API-ключи не нужны.

## Ограничения и проверка

Это OCR-черновик, а не гарантированно полный список. Муар на фотографиях монитора, наклон, обрезанные строки и редкие имена ухудшают результат. Проверка пользователем обязательна; неподходящие строки могут быть пропущены. Фотографии разных классов нужно загружать отдельно.

Проверено локально на приложенном печатном списке: распознавание после выделения столбца, редактирование, перенос, сохранение и повторное открытие в Chromium, ширины 375 и 1440. Режим монитора проверен на приложенных фото №5, №6 и №7: после выделения области списка распознаны все 20 фамилий и имён, без ручного редактирования текста; 7 повторных строк объединены. Каждая строка автоматически сопоставлена с отдельно прочитанным эталоном. В локальном Chromium обработка заняла около 8 секунд; скорость на других устройствах может отличаться. Система не содержит этих имён или ожидаемого количества учеников.

Тесты парсера покрывают составные имена, переносы, отчества, пересечения фотографий, конфликт номеров, пропуски, тёзок и повторный импорт. Реальные фотографии и списки не включены в репозиторий.

Обработка монитора: сглаживание полос в красном канале, выравнивание локальной яркости, оценка наклона, разделение на строки и несколько вариантов ширины букв. Переносы собираются по геометрической близости и подтверждённым словам; одиночный шум панели задач отбрасывается. Общие рекомендации по подготовке изображений: https://tesseract-ocr.github.io/tessdoc/ImproveQuality.html .
