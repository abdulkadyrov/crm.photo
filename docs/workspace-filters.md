# Фильтры списков

Кнопка «Фильтры» рядом с «Оплатой и выдачей» и поиском проектов. Услуги выбираются несколькими чекбоксами с поиском. Съёмка, генерация, печать, оплата, выдача и наличие оценки сходства — раскрывающиеся группы. Диапазон 0–100% задаётся вручную. Изменения применяются только кнопкой «Применить». «Сбросить» в форме сбрасывает черновик, снаружи — текущий фильтр. «Отмена» сохраняет прежние условия. Состояние в памяти изолировано по аккаунту и разделу, при возврате сохраняется.

Все условия пересекаются на одном ребёнке. Выбранные услуги сочетаются через ИЛИ, статусы применяются к выбранным услугам; оплата остаётся статусом ребёнка. В диапазон входят только рассчитанные оценки. При нескольких работах по услуге берётся последняя, среди услуг — минимум рассчитанных оценок. Есть отдельные варианты для ещё не проверенных и неудачных проверок. В проектах/группах остаются карточки с подходящими детьми; число совпадений подписано отдельно от общего количества учеников. В группе скрываются неподходящие дети. Фильтр не меняет данные или статусы. При отсутствии совпадений остаётся панель со счётчиком и сбросом.

Код: js/services/workspace-filters.js, js/ui/workspace-filters.js. Подключение через mountScopeActions в workflow-workspace. Существующие поиски и фильтры не сбрасываются; их скрытие карточек дополнительно сохраняется. Проверки: npm run check и браузер на 319 px.
