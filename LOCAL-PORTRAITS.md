# Локальная подготовка портретов — версия для проверки

Эта сборка не опубликована. На Mac проверены интерфейс демо, логика очереди и сохранение данных. Реальная обработка на RTX 4070, качество лица и полный автономный путь пока НЕ проверены. Рабочую CRM не заменять до приёмки.

Компактный ZIP для Windows содержит приложение, превью каталога и полный макет/маску «Капитана пиратов». Большие видео и печатные оригиналы остальных образов в этот тестовый ZIP не включены; в исходном репозитории они сохранены. Это сборка для проверки портретов, не замена полного каталога.

## Запуск на Windows

1. Распакуйте сборку в `D:\CRMPhoto\app`. Не заменяйте прежнюю CRM и не очищайте её базу.
2. Запустите существующий ComfyUI 0.44.0 на `http://127.0.0.1:8188`, с `--listen 127.0.0.1`. Не используйте `0.0.0.0` и публичные туннели.
3. В ComfyUI нужен узел `ReActorFaceSwap` из [ComfyUI-ReActor](https://github.com/Gourieff/ComfyUI-ReActor) и модель `inswapper_128.onnx`. Нужны также локальные модели обнаружения лица и зависимости ReActor. Установку выполняйте заранее по документации расширения. Все папки ComfyUI, `models`, `input`, `output`, Python и кеши моделей должны находиться на D:. Первый запуск расширения может скачивать модели; до работы с фотографиями завершите настройку и проверьте запуск с отключённым интернетом. Сборка не содержит моделей и не устанавливает их автоматически.
4. Запустите `scripts\local-portraits\start-local.cmd`. По умолчанию используется Python из `D:\ComfyUI_windows_portable\python_embeded\python.exe`; при другом расположении введите полный путь к Python этой установки. Нужен Pillow (обычно уже установлен в ComfyUI).
5. Откройте **http://127.0.0.1:4175**. Это отдельная локальная база браузера. Пользуйтесь одним браузером и этим адресом, чтобы видеть сохранённые заказы. Порт не меняйте.
6. Через **Настройки → Импорт / экспорт → Импорт всех данных** импортируйте `test-fixtures/local-portraits-acceptance.zip` обычным способом. Вручную распаковывать фотографии не нужно. Сначала проверьте импортируемый состав и подтвердите его в CRM. ZIP добавляет отдельный тестовый проект с шестью вымышленными заказами и демонстрационным портретом.

## Один заказ

Откройте ученика → **Подготовить работу** → выберите услугу. Для «Капитана пиратов» исходники берутся только из портретной задачи этого ученика. Если их несколько, выберите по превью. Нажмите **Подготовить черновик**.

Исходник отправляется только локальному ComfyUI. Workflow использует существующие `master.png` и `face-mask.png`: ReActor переносит лицо, затем маска ограничивает изменения областью лица; костюм и фон берутся из исходного макета. Улучшение/восстановление лица отключено. Сходство, возраст, выражение и края маски обязательно проверить глазами; перенос лица не гарантирует точного совпадения.

Комментарий сохраняется в задании и рядом с черновиком. Workflow не исполняет текстовые пожелания: они помечены «Проверьте вручную перед утверждением». LM Studio не требуется.

**Утвердить и создать A4** сохраняет результат в «Готовые работы» и создаёт A4 существующим механизмом CRM. Черновик сам по себе не доступен для печати. **Переделать** сохраняет прежний черновик при ошибке. **Удалить черновик** не удаляет исходники и готовые работы. Уже утверждённые работы повторно не обрабатываются.

## Очередь и ошибки

В классе — **Подготовить работы класса**, в проекте — **Подготовить работы школы**. До старта видны число заданий и причины пропусков. Услуги без настроенного workflow, заказы без портрета, с несколькими портретами или уже имеющимся результатом пропускаются. Задания выполняются по одному; ошибка не останавливает остальные.

Не закрывайте вкладку и окно сервиса во время очереди. После завершения прочитайте итог и ошибки. При выключенном ComfyUI запустите его и повторите обработку. Прежний черновик остаётся на месте. При тайм-ауте сначала проверьте очередь ComfyUI, чтобы не запускать ту же обработку повторно.

Сервис слушает только `127.0.0.1:4175`, проверяет Host/Origin и обращается только к `127.0.0.1:8188`. Исходники, комментарии, workflow и черновики также сохраняются в `D:\CRMPhoto\jobs`; это локальные рабочие файлы. В облако сервис их не отправляет. Для резервной копии заказа используйте ZIP-экспорт CRM; черновики включены в архив.

## Приёмка на рабочем ПК

- На демонстрационном портрете или фото взрослого пройти импорт ZIP → исходник → черновик → утверждение → A4. Проверить правильный заказ, комментарий и сходство.
- В классе/школе проверить: подходящий заказ; нет фото; два фото; другая услуга; ошибочный исходник. После ошибки следующий подходящий заказ должен обработаться.
- Проверить переделку, удаление, повтор очереди, сохранение исходников и утверждённого результата. Проверить ZIP-экспорт/импорт черновика.
- Отключить интернет, оставив localhost, и повторить полный путь. При выключенном ComfyUI проверить понятную ошибку. Записать версию ComfyUI/ReActor и используемые модели.

До успешного выполнения этих пунктов не публиковать интеграцию и не использовать на рабочей базе.
